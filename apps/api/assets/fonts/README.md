# Receipt PDF font

Noto Sans CJK JP Regular, redistributed under the SIL Open Font License in LICENSE.txt.

Source: https://github.com/notofonts/noto-cjk/tree/f8d157532fbfaeda587e826d4cd5b21a49186f7c/Sans

The font is bundled in the API container and subset into each PDF. No customer data or font request is sent to a third-party service at PDF generation time.
